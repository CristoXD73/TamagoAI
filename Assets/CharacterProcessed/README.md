# Character processed

Approved transparent runtime PNG exports and their frame manifest belong here,
organized by source revision. Follow the [asset contract](../../docs/CHARACTER_ASSET_PIPELINE.md)
for names, scales, anchors, timing metadata and memory review. `_work/` is ignored
for derived frames and temporary compression candidates. Final exports are tracked.

After the character implementation handoff, copy only approved frames into the
Watch asset catalog. Do not import this directory wholesale or add fake artwork.
