# Art reference

Store original or redistribution-permitted reference sheets, palette notes and
anatomy/eye studies here. Record creator, source URL, license and intended use.
For references without redistribution rights, record a link rather than copying
an image. References are not runtime assets or final documentation media.

tentacles; see the [asset specification](../../docs/CHARACTER_ASSET_PIPELINE.md).
