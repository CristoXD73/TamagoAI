# Character source

Editable original octopus artwork and approved lossless master exports belong
here, organized by revision (for example `octopus-v001/`). Include a provenance
note with creator, date, rights, canvas/pivot and export settings. Keep large
working histories outside Git; `_work/` is ignored for temporary processing.
No placeholder art or unlicensed third-party artwork belongs here.

Follow the [character asset specification](../../docs/CHARACTER_ASSET_PIPELINE.md).
These files are authoring inputs, not app-bundle resources.
