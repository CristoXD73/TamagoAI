# TamagoAI media

This directory is the stable home for public-facing TamagoAI documentation media.

Planned assets:

- `hero.png` — primary TamagoAI / Apple Watch hero image
- `watch-simulator.png` — current simulator UI
- `character-idle.gif` — subtle idle life
- `character-wander.gif` — autonomous movement
- `character-peek.gif` — offscreen exit and edge peek
- `character-touch.gif` — touch reaction
- `architecture.png` — Watch ↔ gateway ↔ local-AI architecture
- `physical-watch.jpg` — real-device build once verified

## Capture rules

1. Prefer short, tightly cropped GIFs for motion rather than long recordings.
2. Optimize media before committing it; avoid dumping source video into Git.
3. Keep filenames stable so README links survive visual refreshes.
4. Add useful alt text wherever media is embedded.
5. Never imply physical-device verification using simulator imagery.
6. Replace outdated screenshots as the UI changes.
7. Keep final character artwork provenance/licensing documented.

The public README is expected to evolve continuously with the product.
