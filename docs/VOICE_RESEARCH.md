# Tamago's voice: local neural TTS research (2026-09-27)

**Question (owner):** "Find and implement better and natural voices. So it sounds just like when ChatGPT talks
to you." **Constraints** (docs/handoff/VOICE_TASK.md §2): runs **locally** on the owner's Mac mini (Apple M6,
16 GB) next to Ollama; **permissive licenses for code and weights**; no cloud APIs; no voice cloning; never
imitate OpenAI's or any real person's voice; synthesis ≤ ~1 s warm for 1–2 sentences; RAM ideally ≤ 1 GB.

**Method and honesty note.** This is a desk survey: model cards, licenses, repositories and public leaderboards,
all cited. **Nothing here was measured by me**: the cloud sandbox this was written in can't reach Hugging Face
or GitHub release downloads, so no engine was run. Speeds are the projects' own claims or derived from model
size (82 M parameters × 4 bytes ≈ 330 MB fp32). Real numbers come from `Gateway/scripts/voice-samples.js` on the
owner's Mac, which records synthesis time and file size for every clip.

voices", **none of those five are candidates**, and the gateway refuses them (`src/tts.js`). The card doesn't say
which data produced which voice, so a residual provenance question remains for the whole model. The owner should
know it (§4).

## 3. Why synthesis moves to the Mac

- watchOS gives third-party apps **no neural TTS** and **only one system voice** [23]. The natural voice has to be
  made elsewhere, and the owner's own Mac is local, already runs the brain, and has the headroom.
- A 1–2 sentence reply as AAC mono at 24 kHz / 32 kbps is **about 4 KB per second of speech**, well within the
  ~60 KB budget and a trivial Wi-Fi fetch.
- The Watch keeps `AVSpeechSynthesizer` as the automatic fallback, so nothing gets worse when the Mac can't speak.

## 4. Things the owner should know

1. **Kokoro's training data.** The card says Kokoro was trained on permissive/non-copyrighted audio, *including
   synthetic audio from closed TTS models from large providers* [1]. The license is Apache-2.0 and we use stock
   voices only, but the provenance of individual voices isn't disclosed. We exclude the five voices named like
   OpenAI's. If that residual doubt is unacceptable, KittenTTS is the fully separate alternative (same install),
   or Apple's Premium voices on the Mac (personal use only).
2. **espeak-ng (GPL-3.0) inside the runtime.** sherpa-onnx phonemizes English with espeak-ng (the
   `espeak-ng-data` folder in the model packages). espeak-ng is GPL-3.0, and sherpa-onnx has an open issue to
   remove it for that reason [26]. **This doesn't touch our code:** the engine is downloaded by the owner onto
   their own Mac and runs as a separate process; TamagoAI neither links nor redistributes it. It would matter only
   if the engine were ever shipped inside a distributed product.
3. **No watermarking, no cloning.** Chatterbox is MIT but watermarks every output and is designed around reference
   voices. Not needed here.
4. **"Like ChatGPT" is about quality.** We never tune toward, prompt for or pick voices resembling OpenAI's.

## 5. What happens next

1. The local agent runs `Gateway/tools/tts/setup.sh` on the Mac. It installs sherpa-onnx + Kokoro + KittenTTS to
   `/Volumes/Storage/AI/tts/` (≈ 450 MB total, estimated), printing each URL, size and license and asking first.
2. `node Gateway/scripts/voice-samples.js` renders the same six Tamago lines in every candidate voice at two
   speeds, and **measures** synthesis time and size, into a local listening page.
3. The owner picks by ear. `TAMAGO_TTS=kokoro TAMAGO_TTS_VOICE=<pick>` turns it on (D-121, PROTOCOL_V1 §16).
